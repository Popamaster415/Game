# Adventure Game 

📝Описание:
Adventure Game - это 2D игра созданная на Python с использованием библиотеки Pygame в которой вы можете бегать по карте, избегать препятствия и собирать монетки 

🛠Технологии:
# Python 
# Pygame
# Json

🚀Установка и запуск:
Клонируйте репозиторий 
Усовершенствуйте игру
Установите зависимости
Pygame
Запустите игру
